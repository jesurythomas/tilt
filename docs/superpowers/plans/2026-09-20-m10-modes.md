# Module 10 — Modes: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Classic, Gauntlet and Code Red playable from start to death. Port `GauntletMaze.ts` in full (sim in `sim/gauntlet_maze.gd`, drawing in `EntityLayer`). Route the active mode through every `RunController` step that the TS passes `activeMode` to. Port the mode backgrounds and overlays in `TiltRenderer.ts` and its mode announcement banner. Add a temporary Pause-sheet mode picker so a mode can be chosen on the phone before M11's menu exists.

**Architecture:** Most of the mode code is already ported, and M10 connects it. M3 ported the swarm's code-red/gauntlet branches, `spawn_mode_armada` and `trigger_gauntlet_formation`. M4 ported the weapon orb timer. M2 ported the gauntlet score tick and `set_mode_multiplier`, and M7 ported the three `ModeConfig`s and `settings.mode` persistence. M10 adds `GauntletMaze` (a `RefCounted` sim system owned by `RunController`, spec §4.2's `sim/gauntlet_maze.gd`), captures the run's mode at `reset_run`, and passes it to steps 4–8 in spec §5.4's order. Drawing follows spec §5.5: the grid layer gets the mode background, grid tint and overlays; the entity layer draws the maze first; the effect layer draws the banner on top. Mode choice is written to `GameOptionsManager.settings` through `GameRoot.set_game_mode`, and it takes effect at the next `reset_run`.

**Tech Stack:** Godot 4.7.2-stable, GDScript (static typing enforced), GUT headless, gdtoolkit 4.5.0.

**Spec:** `docs/superpowers/specs/2026-09-20-peril-point-godot-port-design.md` §8 Module 10 (also §4.2 file layout, §5.1–§5.5, §6.3 Tier 1). ## The five port laws (restated — binding on every task)

1. **No invented numbers.** Every numeric literal carries `# PORT: <ts path>:<line>`. Exempt: `0`, `1`, `-1`, `0.0`, `1.0`, array indices.
2. **No silent improvement.** Odd TS is ported as written with `# PORT-NOTE: … — preserved deliberately`.
3. **One file, one file.** `GauntletMaze.ts` → `sim/gauntlet_maze.gd` (its `render()` body goes to `EntityLayer`, as every sim file's does — `entity_layer.gd:1-8`). Same members, same order, snake_cased.
4. **Nothing new.** Only what the TS, a spec line, or a ruling below requires.
5. **Stop, do not guess.** Ambiguity → record in `godot/HANDOFF.md` and ask.

## Review Focus

These are the inputs the spec implies that are most likely to bite a player. Each one has its test in the named task.

1. **The maze on the phone's arena width (~780 px) and at the desktop scale ceiling (1.75).** Every wall segment must lie inside `0..width` with positive width, and every row must keep at least one gap. Pattern 1 needs `width >= 750`, so it can drop out on narrow arenas. Task 1 `test_segments_stay_inside_the_arena_at_every_width`.

4. **Dying inside the banner's 2.8 s window.** The banner must not stay frozen under the Run over sheet. Task 4 `test_banner_hides_when_the_run_ends`.
5. **The Pause sheet with a third control row, at 844×390 and 2340×1080.** Nothing leaves the screen, every segment is ≥ 48 × ui_scale, and the columns do not overlap. ```gdscript
## test_gauntlet_maze.gd
## PORTS: nothing — new file, covers src/sim/gauntlet_maze.gd (spec §6.3 Tier 1)
extends GutTest
## Proves the maze's rows, scaling, scroll/recycle, the four spawn patterns'
## geometry, blocking, pushing and the floor crush.

const BOUNDS: Vector2 = Vector2(800.0, 600.0)

var _maze: GauntletMaze
var _player: PlayerShip
var _particles: ParticleEngine
var _crushes: Array[int] = [0]


func before_each() -> void:
	seed(20260924)
	_maze = GauntletMaze.new()
	_player = PlayerShip.new(BOUNDS.x * 0.5, BOUNDS.y * 0.5)
	_particles = ParticleEngine.new()
	_crushes = [0]


func _on_crushed() -> void:
	_crushes[0] += 1


## One solid full-width row whose top edge is at `y`.
func _solid_row(y: float, height: float) -> GauntletMaze.GauntletWallRow:
	var row: GauntletMaze.GauntletWallRow = GauntletMaze.GauntletWallRow.new()
	row.id = 99
	row.y = y
	row.height = height
	row.segments = [GauntletMaze.WallSegment.new(0.0, BOUNDS.x)]
	row.gaps = [GauntletMaze.MazeGap.new(0.0, 0.0)]
	return row


func test_reset_builds_four_rows_a_spacing_apart() -> void:
	_maze.reset(BOUNDS.x, BOUNDS.y)
	assert_eq(_maze.rows.size(), 4, "GauntletMaze.ts:54")
	for i: int in range(4):
		assert_eq(_maze.rows[i].id, i + 1, "ids from 1 (:50, :192)")
		assert_almost_eq(_maze.rows[i].y, -230.0 * i, 0.0001, ":56")
		assert_almost_eq(_maze.rows[i].height, 22.0, 0.0001, ":41")
		assert_false(_maze.rows[i].gaps.is_empty(), "every row has a gap")
	assert_almost_eq(_maze.current_speed, 75.0, 0.0001, ":51")


func test_set_scale_clamps_and_scales_geometry() -> void:
	_maze.set_scale(3.0)
	assert_almost_eq(_maze.scale, 1.8, 0.0001, ":37")
	assert_almost_eq(_maze.wall_height, 22.0 * 1.8, 0.0001, ":41")
	assert_almost_eq(_maze.row_spacing, 230.0 * 1.8, 0.0001, ":45")
	_maze.set_scale(0.1)
	assert_almost_eq(_maze.scale, 0.5, 0.0001, ":37")
	_maze.reset(BOUNDS.x, BOUNDS.y)
	assert_almost_eq(_maze.current_speed, 75.0 * 0.72, 0.0001, "max(0.72, scale) (:51)")


func test_speed_follows_score_and_time() -> void:
	_player.is_dead = true
	_maze.reset(BOUNDS.x, BOUNDS.y)
	_maze.update(0.0, BOUNDS, _player, 40000, 100.0, _particles, _on_crushed)
	# (75 + min(130, 40000/20000*45) + min(75, 100*1.2)) * 1.0 (:213-216)
	assert_almost_eq(_maze.current_speed, 75.0 + 90.0 + 75.0, 0.0001)
	_maze.update(0.0, BOUNDS, _player, 100000, 10.0, _particles, _on_crushed)
	assert_almost_eq(_maze.current_speed, 75.0 + 130.0 + 12.0, 0.0001, "score bonus caps at 130")


func test_rows_scroll_recycle_and_respawn() -> void:
	_player.is_dead = true
	_maze.reset(BOUNDS.x, BOUNDS.y)
	# One 9 s step at 75 px/s moves every row 675 px: 675, 445, 215, -15.
	_maze.update(9.0, BOUNDS, _player, 0, 0.0, _particles, _on_crushed)
	var ys: Array[float] = []
	for row: GauntletMaze.GauntletWallRow in _maze.rows:
		ys.append(row.y)
	# 675 >= 600 + 60 is culled (:224); the highest (-15) is > -50, so one row
	# spawns a spacing above it (:234-237).
	assert_eq(ys.size(), 4)
	assert_almost_eq(ys[0], 445.0, 0.0001)
	assert_almost_eq(ys[1], 215.0, 0.0001)
	assert_almost_eq(ys[2], -15.0, 0.0001)
	assert_almost_eq(ys[3], -245.0, 0.0001)
	assert_eq(_maze.rows[3].id, 5, "next id continues")


func test_segments_stay_inside_the_arena_at_every_width() -> void:
	var patterns_seen: Dictionary[int, bool] = {}
	for scale: float in [1.0, 1.75]:
		for width: float in [780.0, 844.0, 1280.0, 2340.0]:
			_maze.set_scale(scale)
			for n: int in range(50):
				_maze.reset(width, BOUNDS.y)
				for row: GauntletMaze.GauntletWallRow in _maze.rows:
					patterns_seen[row.pattern] = true
					assert_false(row.gaps.is_empty(), "a row with no gap at %s" % width)
					for seg: GauntletMaze.WallSegment in row.segments:
						assert_gt(seg.width, 0.0, "segment width at %s" % width)
						assert_gte(seg.x, 0.0, "segment start at %s" % width)
