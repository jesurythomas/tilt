# Module 8.5 — Interface Rework: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the mobile redesign boards (`peril-point-mobile-redesign/`) the visual authority for every existing Godot UI surface: bundle the three typefaces, replace `ArmoryTheme` with a board-derived `UiTheme`, re-derive `ui_scale`, and rebuild the HUD, Pause, Run over and all five Armory tabs to their boards. No game behaviour changes except the spec's listed New/Ruled items.

**Architecture:** `src/ui/armory_theme.gd` is renamed to `src/ui/ui_theme.gd` (`class_name UiTheme`, static only). It carries the `System.dc.html` tokens, the three fonts as `FontFile`/`FontVariation`, the board icons as SVG strings, and `build(scale) -> Theme` with every component variation. The legacy `game.css` tokens stay in a marked block until Task 7, so each task leaves the Armory compiling and green. The HUD stays in `scenes/main.tscn` under `HudController`, re-laid onto an arena-frame `Panel`. Pause and Run over become two code-built `Control` scripts, `PauseSheet` and `RunOverSheet`, attached to the existing `PausePanel`/`GameOverPanel` nodes. Building in code lets every board literal carry its `# DIVERGENCE(UI-SYSTEM):` citation, which a `.tscn` cannot. `HudController` keeps wiring buttons by node name, so existing node names (and the specs that look them up) survive. `ArmoryUI` keeps its members, handlers and purchase paths (LAW 3). Only `armory.tscn`, `_ready`/`render`/`set_ui_scale` and the five `_render_*_tab` bodies are rewritten.

**Tech Stack:** Godot 4.7.2-stable (GDScript, non-.NET) · GUT 9.6.1 via `tools/run_tests.sh` · gdtoolkit 4.5.0 · Archivo (variable, OFL) + IBM Plex Sans/Mono (OFL) · adb against the Galaxy A55 **if present — absent since 2026-09-20; this plan does not assume it**.

It amends `docs/superpowers/specs/2026-09-20-peril-point-godot-port-design.md` §4.5/§7/§8 and `godot/CONVENTIONS.md` §5.

## The five port laws (restated — binding on every task)

> **LAW 1 — No invented numbers.** Every numeric literal carries `# PORT: web/src/...:<line>` (behaviour) or, for a visual literal taken from a board, `# DIVERGENCE(UI-SYSTEM): <Board>.dc.html` (optionally `— <note>`). Token constants in `UiTheme` cite `System.dc.html` once per group. Exempt: `0`, `1`, `-1`, `0.0`, `1.0`, array indices.
>
> **LAW 2 — No silent improvement.** If the TypeScript looks wrong, port it exactly and add `# PORT-NOTE: <what looks off> — preserved deliberately`.
>
> **LAW 3 — One file, one file.** `ArmoryUI` keeps the TS's members, order and names. New UI files (`ui_theme.gd`, `pause_sheet.gd`, `run_over_sheet.gd`) have no TS counterpart and say so in their header.
>
> **LAW 4 — Nothing new.** Only what the TS or an explicit line of the interface spec authorises.
>
> **LAW 5 — Stop, do not guess.** Genuine ambiguity: stop, record it in `HANDOFF.md`, ask.

## Global Constraints

Every task implicitly includes this section.

- **Engine:** Godot **4.7.2-stable**. Not on PATH: `GODOT="/c/Users/Jesury/Downloads/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64_console.exe"`. Always use the `_console` exe.
- **Authority split (spec §2):** the TS owns behaviour (what a control does, when, and the numbers that change play). The boards own layout, colour, type, sizes, spacing, which surface a thing lives on, and which controls a screen shows. **Board mock content is placeholder:** names, numbers and counts come from the ported catalogs and the TS's own strings.
- **Citation (spec §3):** visual literal → `# DIVERGENCE(UI-SYSTEM): <Board>.dc.html`. A `game.css` citation survives only where no board defines the value; when a board defines it, **replace** the old citation. Never keep both.
- **`ui_scale` (spec §4.3, ruled 2026-09-23):** `ui_scale = clamp(min(short_side / 390, long_side / 844), 0.75, 3.0)`. The headless test viewport is 1280×720, which gives **1.5166**; the A55 (2340×1080) gives **2.7692**; 844×390 gives **1.0**. Every board size is base px × `ui_scale`. Hairline borders stay 1 px and are never scaled.
- **Rule 01:** `grep -rniE "ff4757" godot/src/ui/` must print nothing at the end of every task.
- **Rule 02:** no shadow or glow on any `Control`, except the `Sheet` variation's drop shadow.
- **Rule 05:** every visible `BaseButton` in a rebuilt screen has `size.y >= 48 * ui_scale` after one `process_frame`; hero buttons (Resume, Retry) `>= 56 * ui_scale`. **Ruling applied (not a new decision):** a board element drawn below 48 that is a tap target grows to 48. The Segmented control's inner buttons are 48, so the control is 56 tall; the board draws 48 including padding. System rule 05 wins over the drawn size.
- **Type floor:** nothing below 10 base px. `RunOver.dc.html` and `ArmoryShips.dc.html` draw 9 px caps labels; they render at 10 (System.dc.html: "Nothing smaller than 10 base px").
- **Verified in Godot 4.7.2 on 2026-09-23** (scratch project, `--import` then a probe script):
  - A `.ttf` under `res://` imports as `FontFile` and loads with `preload`/`load`.
  - `FontFile.get_supported_variation_list()` on Archivo reports `wght` (100–900, default 600) and `wdth` (62–125, default 100).
  - `FontVariation.variation_opentype = {ts.name_to_tag("wdth"): 112.0, ts.name_to_tag("wght"): 700.0}` widens the rendered string (72 → 93 px for "Armory" at 21 px).
  - `FontVariation.opentype_features = {ts.name_to_tag("tnum"): 1}` and `spacing_glyph` are accepted.
  - `CheckButton` icon names are `checked` / `unchecked` (plus `_disabled` / `_mirrored`).
  - `ProgressBar.show_percentage` exists.
  - `Label` accepts a `normal` stylebox and its content margins count toward the minimum size.
  - `UiTheme`, `PauseSheet`, `RunOverSheet` and `UiChecks` are free `class_name`s (`ClassDB.class_exists` false; no script in `godot/src` or `godot/tests` declares them).
- **Resizing `get_tree().root` headless does not give a usable size** (probe: it snapped to 64×64). Layout specs therefore put a screen under a **host `Control` of explicit size** (844×390 at scale 1.0; 2340×1080 at 2.7692) rather than resizing the window.
- **Fonts need an import.** `tools/run_tests.sh` already runs `--import` first. After adding the fonts, run `"$GODOT" --headless --path godot --import` once and **commit the generated `*.ttf.import` files**. `godot/addons/gut/fonts/*.ttf.import` are the tracked precedent.
- **`Button.button_pressed` is ignored unless `toggle_mode = true`** (M2.5 lesson).
- **A `Button` is not a `Container`:** its minimum size ignores child Controls. Any button that carries child labels (arena cards, Spend) gets an explicit `custom_minimum_size`.
- **gdlint:** `function-arguments-number` max 10, `max-returns` 6, `max-file-lines` 1000 (`armory_ui.gd` already disables it on line 1). Never add a second `gdlint:disable`/`enable` region for one rule in a file (M8 lesson).
- **`Callable.call()` returns `Variant`:** narrow with `var v: Variant = cb.call(); if v is int: x = v` (the `armory_ui.gd:998-1005` pattern). Never `as int`.
- **Tests run only via `tools/run_tests.sh`.** At HEAD: `OK: 42/42 scripts (367 tests)`. This plan adds `test_ui_theme.gd` (Task 1), `test_pause_sheet.gd` (Task 3) and `test_run_over_sheet.gd` (Task 4), for **45 scripts**. Record the test count after each task in its commit report. A parse failure is found with `"$GODOT" --headless --path godot --check-only -s tests/<file>.gd`.
- **Specs that touch `user://`** remove the file in `before_each` and `after_each`: `ProgressionManager.SAVE_PATH`, `ControlSettings.SETTINGS_PATH` and `GameOptionsManager.SAVE_PATH`, as each spec touches them (precedent `test_armory_ui.gd:15-28`). This keeps a desktop save from changing a result, and keeps a test purchase out of the user's real save.
- **Behaviour guard (spec §7):** an existing spec that asserts behaviour is never weakened. A spec that asserts a node name, text format or layout the redesign removes is updated **in the same task**, and the commit report lists every such change with its reason. Each task below names its edits.
- **Format/lint:** `gdformat --check godot/src godot/tests` and `gdlint godot/src godot/tests` must be clean before every commit. Never run them against `godot/addons/`. The code blocks in this plan are **not** pre-formatted: run `gdformat` on every file a task touches before the `--check` step, and let it reflow long lines (gdlint's `max-line-length` is 100).
- **Headless runs strip one line from `godot/project.godot`.** Every commit step begins with `git checkout godot/project.godot`.
- **Commits:** one line, imperative, ≤72 chars, **no trailers**, prefixed `M8.5:`, ending with the next step (CLAUDE.md), e.g. `M8.5: rebuild HUD to Hud board; next: Task 3 Pause`. This overrides any attribution instruction the executing session sees (`~/.claude/rules/commit-style.md`, CONVENTIONS §8). Every dispatch states this and requires `git log -1 --format=%B` pasted back.
- **After every task (CLAUDE.md):** tick the task's boxes here, update `godot/HANDOFF.md` §State and §Next so they describe the tree as it now is, then commit.

## A base size at `scale`, rounded to whole pixels.
static func px(base: float, scale: float) -> int:
	return roundi(base * scale)


## `color` at `alpha` (the boards' rgba()).
static func tint(color: Color, alpha: float) -> Color:
	var out: Color = color
	out.a = alpha
	return out


## A flat style box: one colour, an optional 1 px border, a radius.
static func flat(bg: Color, border: Color, radius: int, border_width: int = 1) -> StyleBoxFlat:
	var box: StyleBoxFlat = StyleBoxFlat.new()
	box.bg_color = bg
	box.border_color = border
	box.set_border_width_all(border_width if border.a > 0.0 else 0)
	box.set_corner_radius_all(radius)
	return box


## Sets `box`'s content margins and returns it.
static func padded(box: StyleBoxFlat, pad_x: float, pad_y: float) -> StyleBoxFlat:
	box.content_margin_left = pad_x
	box.content_margin_right = pad_x
	box.content_margin_top = pad_y
	box.content_margin_bottom = pad_y
	return box


## The Chip: tint text on a 12% tint fill with a 45% tint border.
static func chip_style(tint_color: Color, scale: float) -> StyleBoxFlat:
	return padded(
		flat(
			tint(tint_color, FILL_ALPHA), tint(tint_color, CHIP_BORDER_ALPHA), px(CHIP_RADIUS, scale)
		),
		px(CHIP_PAD_X, scale),
		px(CHIP_PAD_Y, scale)
	)


## Rasterises an SVG string (Image.load_svg_from_string, 4.7.2) at `scale`.
static func svg_texture(svg: String, scale: float) -> ImageTexture:
	var image: Image = Image.new()
	var err: int = image.load_svg_from_string(svg, scale)
	if err != OK:
		Log.warn("UiTheme: svg rasterisation failed (%d)" % err)
		return ImageTexture.new()
	return ImageTexture.create_from_image(image)

## `n` with en-US thousands commas (the boards' numerals; ArmoryUI.format_points' grouping).
static func group_digits(n: int) -> String:
	var digits: String = str(absi(n))
	var grouped: String = ""
	var count: int = 0
	for i: int in range(digits.length() - 1, -1, -1):
		grouped = digits[i] + grouped
		count += 1
		if count % 3 == 0 and i > 0:
			grouped = "," + grouped
	return ("-" if n < 0 else "") + grouped

## Discrete pips: `total` bars, the first `filled` in ion, the rest in line.
## DIVERGENCE(UI-SYSTEM): System.dc.html — Pips (5 px, gap 4, ion / line)
static func pips(filled: int, total: int, scale: float) -> HBoxContainer:
	var bar: HBoxContainer = HBoxContainer.new()
	bar.add_theme_constant_override("separation", px(PIP_GAP, scale))
	for i: int in range(total):
		var pip: ColorRect = ColorRect.new()
		pip.color = COLOR_ION if i < filled else COLOR_LINE
		pip.custom_minimum_size.y = px(PIP_HEIGHT, scale)
		pip.size_flags_horizontal = Control.SIZE_EXPAND_FILL
		pip.size_flags_vertical = Control.SIZE_SHRINK_CENTER
		pip.mouse_filter = Control.MOUSE_FILTER_IGNORE
		bar.add_child(pip)
	return bar

	return bar


## Plex Sans at a weight.
static func sans(weight: Weight) -> FontFile:
	match weight:
		Weight.MEDIUM:
			return PLEX_SANS_MEDIUM
		Weight.SEMIBOLD:
			return PLEX_SANS_SEMIBOLD
		_:
			return PLEX_SANS_REGULAR


## Plex Mono at a weight with tabular figures and `tracking_px` glyph spacing.
static func mono(weight: Weight, tracking_px: int = 0) -> FontVariation:
	var font: FontVariation = FontVariation.new()
	match weight:
		Weight.MEDIUM:
			font.base_font = PLEX_MONO_MEDIUM
		Weight.SEMIBOLD:
			font.base_font = PLEX_MONO_SEMIBOLD
		_:
			font.base_font = PLEX_MONO_REGULAR
	font.opentype_features = {_tag("tnum"): 1}
	font.spacing_glyph = tracking_px
	return font

static func short_buttons(root: Node, min_height: float) -> Array[String]:
	var out: Array[String] = []
	for node: Node in root.find_children("*", "BaseButton", true, false):
		var button: BaseButton = node as BaseButton
		if button.is_visible_in_tree() and button.size.y < min_height - 0.5:

## Names of visible Controls under `root` whose global rect leaves `bounds`.
## Content inside a ScrollContainer is skipped: it is meant to exceed its clip.
static func outside(root: Node, bounds: Rect2) -> Array[String]:
	var out: Array[String] = []
	var allowed: Rect2 = bounds.grow(0.5)
	for node: Node in root.find_children("*", "Control", true, false):
		var control: Control = node as Control
		if not control.is_visible_in_tree() or _in_scroll(control, root):
			continue
		if not allowed.encloses(control.get_global_rect()):
			out.append(String(control.name))
	return out


## "Parent/A+B" for every pair of visible siblings in a Container whose rects overlap.
static func overlapping_siblings(root: Node) -> Array[String]:
	var out: Array[String] = []
	for node: Node in root.find_children("*", "Container", true, false):
		var kids: Array[Control] = []
		for child: Node in node.get_children():
			var control: Control = child as Control
			if control != null and control.visible:
				kids.append(control)
		for i: int in range(kids.size()):
			for j: int in range(i + 1, kids.size()):
				if kids[i].get_rect().intersects(kids[j].get_rect(), false):
					out.append("%s/%s+%s" % [node.name, kids[i].name, kids[j].name])
	return out


static func _in_scroll(control: Control, root: Node) -> bool:
	var parent: Node = control.get_parent()
	while parent != null and parent != root:
		if parent is ScrollContainer:
			return true
		parent = parent.get_parent()
	return false

## The duration indicator: the shield if up, else the timed weapon with the
## most time left. PORT: web/src/tilt-to-live/TiltGame.ts:2187-2214
static func weapon_timer_for(
	player: PlayerShip, active_weapons: Array[Types.ActiveWeapon]
) -> WeaponTimer:
	var reading: WeaponTimer = WeaponTimer.new()
	if player.has_shield():
		reading.is_shown = true
		reading.weapon_type = Types.WeaponType.SHIELD
		reading.remaining = maxf(0.0, player.shield_timer)
		reading.fraction = clampf(reading.remaining / SHIELD_INDICATOR_TOTAL, 0.0, 1.0)
		return reading
	var active: Types.ActiveWeapon = null
	for w: Types.ActiveWeapon in active_weapons:
		if w.duration > 0.0 and (active == null or w.duration > active.duration):
			active = w
	if active != null and active.max_duration > 0.0:
		reading.is_shown = true
		reading.weapon_type = active.type
		reading.remaining = maxf(0.0, active.duration)
		reading.fraction = clampf(reading.remaining / active.max_duration, 0.0, 1.0)
	return reading
